AI Speaking Practice｜隱私政策

最後更新：2026-10-22

本政策適用於本 App 的外語對話練習與「強迫背單字」功能。本 App 不要求建立帳號。

1. 儲存在手機上的資料

單字學習進度、作答歷史、錯題、收藏、統計、學習額度、對話紀錄、收藏句子與設定儲存在手機上，不會自動上傳到開發者的伺服器。Android 自動備份已停用。背單字與錯題複習可以離線使用。

2. 外語對話與 Google Gemini

使用對話功能時，輸入或語音辨識後的文字，以及產生回覆所需的對話上下文，會傳送至 Google Gemini，以提供回覆、翻譯及學習建議。請避免輸入敏感個人資料。

如未提供個人 Gemini API Key，本 App 可使用開發者提供的共用 API Key；無論使用哪一種 Key，對話內容均會送至 Google Gemini 處理。使用者輸入的個人 API Key 儲存在裝置的安全儲存空間，並隨 Gemini 請求送交 Google 驗證。Google 對資料的保留與使用依其條款及服務設定而定。

3. 麥克風與發音

麥克風用於對話練習的語音辨識。語音辨識與文字轉語音由裝置上選用的服務提供，是否連線與傳送語音資料取決於該服務及設定。開發者不建立原始錄音的雲端資料庫。

4. 背單字所需權限

只有進入「強迫背單字」功能時，App 才會引導檢查及申請相關權限；單純使用外語對話練習，不需要背單字的懸浮視窗、電話狀態或通知權限。已啟用的解鎖學習服務可在離開該頁後繼續執行，直到使用者停用或系統停止服務。

顯示在其他 App 上層（啟用解鎖單字卡所需）：用於解鎖後顯示可關閉的單字卡或複習提醒，不讀取其他 App 的畫面內容，也不鎖住手機。

電話狀態（選用）：用於偵測一般來電，立即移除單字卡並停止發音；不讀取電話號碼、聯絡人或通話紀錄。未允許時仍可使用，但來電避讓可能受限，請隨時使用略過。網路通話的偵測依裝置狀況而異。

通知（選用）及背景執行：用於維持解鎖學習並提供停止學習的操作。你可以隨時關閉學習功能或調整系統權限。手機重新開機後，若學習功能原本已啟用且系統允許通知，App 可能顯示提醒通知，請你自行開啟 App 重新啟動學習服務；不會在開機時自動顯示單字卡。

5. 廣告與同意選項

本 App 使用 Google AdMob 顯示廣告。Google 及其廣告合作夥伴可能處理裝置資訊、廣告識別碼、IP 位址、廣告互動及診斷資料。必要時會顯示廣告同意表單；如提供「廣告隱私選項」，可從首頁調整同意設定。單字卡與背景服務不展示廣告。

App 會讀取公開遠端設定以管理廣告與版本資訊；連線服務可能取得一般網路請求資訊，例如 IP 位址。背單字學習不需要網路，也不需要觀看廣告才能恢復學習。

6. 管理與刪除資料

你可以從系統設定撤銷權限、停止服務、清除 App 資料或解除安裝。清除資料或解除安裝會刪除本機學習與對話紀錄，無法由開發者還原。第三方服務已處理資料的管理及刪除，請依該服務的隱私設定與申請管道辦理。
