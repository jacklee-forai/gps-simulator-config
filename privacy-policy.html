GPS 模擬器｜位置模擬－隱私權政策

最後更新：2026-09-06

1. 位置資料與 GPS 模擬

本 App 需要位置權限才能取得目前位置並使用 Android Mock Location。使用者選擇的模擬起始位置、方向、速度及 App 產生的模擬座標主要在裝置本機處理，用於 GPS 模擬。本開發者沒有自行建立的 GPS 位置歷史資料庫，也不會因 GPS 模擬功能將這些資料傳送至開發者自有伺服器。

2. 地圖與第三方網路服務

本 App 的地圖畫面使用 Leaflet JavaScript 地圖函式庫，Leaflet 的 JavaScript 檔案由 unpkg.com 載入；地圖圖磚由 OpenStreetMap 提供。顯示地圖時，App 會向這些第三方服務發出必要的網路請求。

地圖圖磚請求會包含完成網路請求所需的資訊，例如 IP 位址、裝置與網路環境相關資訊，以及請求的地圖圖磚。由於地圖圖磚對應特定地理區域，第三方地圖服務可能由請求內容推知使用者當時正在查看的地圖區域。

這些地圖網路請求的用途是顯示地圖，不是將 GPS 模擬座標上傳給本 App 開發者的伺服器。

Leaflet、unpkg.com、OpenStreetMap、Google Mobile Ads/AdMob、Google UMP、GitHub 等第三方服務各自可能依其服務政策處理 IP 位址、裝置資訊、請求紀錄或其他必要資料；其實際資料處理方式以各服務當時公布的隱私權政策為準。

3. 廣告與 UMP

若遠端設定啟用廣告，本 App 可能使用 Google Mobile Ads（AdMob）與 Google UMP。廣告是否個人化及可使用的廣告服務模式，會依使用者的同意狀態、所在地區及 Google 廣告服務規則處理。拒絕個人化廣告不等於一定不會看到廣告。

4. GitHub 遠端設定

App 可能讀取 GitHub 上公開的靜態 config.json，只用於取得是否啟用廣告的設定。該檔案不包含使用者個人資料，也不是 GPS 模擬資料上傳服務。

5. 我們不收集的資料

本 App 不要求使用者建立帳號，也不由開發者收集姓名、電話、電子郵件、聯絡人、照片、密碼或付款資料。

6. 資料保留與刪除

開發者不建立 GPS 位置歷史資料庫，因此沒有由開發者提供的 GPS 歷史資料刪除流程。第三方服務的資料保留與刪除，依各第三方服務政策及使用者可用的設定／權利處理。

7. 兒童隱私

本 App 不以兒童為主要目標使用者。若第三方服務適用不同的兒童資料處理規則，則依其政策處理。

8. 政策更新與聯絡方式

本政策可能因 App 功能、第三方服務或法規變更而更新。最新版本會公布於本 App 的隱私權政策頁面。開發者聯絡方式以 Google Play 商店頁面公布的開發者聯絡資訊為準。
