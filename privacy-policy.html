繁體中文

本政策適用於「GPS 模擬器｜位置模擬」（套件名稱：com.jacklee.gpssimulator）。開發者及隱私聯絡人：李家豪；電子郵件：a0980500032@gmail.com。

1. App 處理的資料與用途

  • 精確或約略位置：取得使用者目前位置、顯示地圖及在裝置上產生模擬位置。選擇的起點、方向、速度及模擬座標主要在裝置本機處理。開發者沒有建立位置歷史資料庫，也不會把這些座標傳到開發者自有伺服器。
  • App 操作與診斷資料、IP 位址及裝置識別碼：若遠端設定啟用廣告，Google Mobile Ads（AdMob）可能為廣告、分析及防詐騙而自動收集或分享 IP 位址、App 啟動／點擊／影片觀看等互動、效能與診斷資料，以及廣告 ID、App Set ID 或其他適用的裝置／帳戶識別碼。IP 位址可能用於推估約略位置。資料傳輸使用 TLS。
  • 同意狀態：Google User Messaging Platform（UMP）依所在地區及已發布的隱私訊息管理廣告同意與隱私選項。適用時，App 內會顯示「廣告隱私選項」供使用者修改選擇。拒絕個人化廣告不代表一定不會顯示非個人化或受限制的廣告。

2. 地圖與遠端設定

地圖畫面會向 unpkg 取得 Leaflet 程式，並向 OpenStreetMap 取得地圖圖磚。這些請求可能包含 IP 位址、瀏覽器／裝置與網路資訊、請求時間，以及可反映使用者正在查看之地理區域的圖磚座標。App 也會向 GitHub 讀取公開的設定檔，用於廣告開關及最低支援版本／強制更新；該請求不包含模擬座標，但 GitHub 可能處理一般請求紀錄及 IP 位址。

3. 分享對象

資料可能由下列服務依其角色與政策處理：Google AdMob／UMP、OpenStreetMap、unpkg（由 Cloudflare 提供）、GitHub。開發者不出售使用者的精確位置，亦不將精確位置提供給廣告服務。

4. 保留、刪除與安全

開發者不建立帳號，也不建立 GPS 位置歷史資料庫，因此沒有由開發者持有的帳號或位置歷史可供刪除。App 本機設定可透過 Android 的「清除儲存空間」或移除 App 刪除。第三方服務各自依其政策保留、保護及刪除資料；使用者可使用 Android 廣告 ID 控制與 App 內廣告隱私選項管理適用選擇。網路連線使用 HTTPS／TLS；App 禁止明文 HTTP 流量。

5. 其他

本 App 不要求帳號，也不由開發者收集姓名、電話、聯絡人、照片、密碼或付款資料。本 App 不以兒童為主要目標使用者。政策因功能、供應商或法規變更時會更新此頁日期。

English

This policy applies to “GPS Simulator | Location Simulation” (package com.jacklee.gpssimulator). Developer and privacy contact: Jia-Hao Lee (李家豪), a0980500032@gmail.com.

Data and purposes

The app uses precise or approximate location to obtain the device's current location, display the map, and generate mock locations on the device. Selected starting points, direction, speed, and simulated coordinates are mainly processed locally. The developer does not maintain a location history database or send those coordinates to a developer-owned server.

When ads are enabled by remote configuration, Google Mobile Ads may automatically collect or share IP address, app interactions, diagnostics, advertising ID, App Set ID, and other applicable device or account identifiers for advertising, analytics, and fraud prevention. IP address may be used to estimate general location. Google UMP manages consent and privacy choices based on region and the messages published by the developer. Where required, the app displays an “Ad privacy choices” entry point.

Maps, configuration, and recipients

The map requests Leaflet from unpkg and map tiles from OpenStreetMap. These services may receive IP address, device/network request information, time, and tile coordinates that indicate the map area being viewed. The app reads a public GitHub configuration for ads and minimum supported version/forced update; this request does not include simulated coordinates. Data may be processed by Google AdMob/UMP, OpenStreetMap, unpkg/Cloudflare, and GitHub under the policies linked in the Chinese section. The developer does not sell precise location or provide precise location to advertising services.

Retention, deletion, and security

The app has no user accounts and the developer stores no location history. Local app settings can be removed by clearing app storage or uninstalling the app. Third parties retain and delete data under their own policies. Users can use Android advertising ID controls and the in-app privacy choices where available. Network traffic uses HTTPS/TLS and cleartext HTTP is disabled.

The developer does not request or collect names, phone numbers, contacts, photos, passwords, or payment information. The app is not primarily directed to children. This policy will be updated when features, providers, or applicable requirements change.
